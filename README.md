# BidKing Fraction Helper

《BidKing：竞拍之王》辅助脚本，用于根据游戏中显示的两位小数平均值，反推出可能的道具数量组合。

## 用途

游戏界面可能只展示一个平均值，例如 `3.81`。这个脚本会枚举一定范围内的分数 `a / b`，并判断它们在不同保留两位小数规则下，是否会显示成输入的平均值。

可以把结果理解为：

- `a`：可能的总数量、总点数或总价值
- `b`：可能的道具数量、人数或分组数量
- `a / b`：真实平均值
- 输入值：游戏中显示的平均值

脚本会优先标记命中“舍去/截断”规则的结果。历史数据中曾出现过 `3.81` 的验证样本，因此这类结果会被标记为【优先考虑】。

## 运行环境

- Python 3
- 无第三方依赖

## 使用方法

在项目目录中运行：

```bash
python main.py
```

程序启动后输入游戏中看到的平均值，最多保留小数点后 2 位：

```text
请输入一个小数，最多保留小数点后 2 位；直接回车或输入 q 退出:
```

输入示例：

```text
3.81
```

退出程序：

```text
q
```

也可以直接回车退出。

## 匹配规则

脚本会枚举 `1..limit` 范围内的所有 `a / b` 组合，并分别计算：

- 舍去：直接截断到小数点后 2 位
- 四舍五入：按常规四舍五入保留 2 位
- 进一法：向上进位到小数点后 2 位

默认参数：

```python
limit = 100
top_k = 30
```

含义：

- `limit`：分子和分母的最大枚举值
- `top_k`：最多显示的匹配结果数量

## 排序规则

匹配结果会按以下规则排序：

1. 命中舍去/截断规则的结果优先
2. `分子 + 分母` 越小越靠前
3. 分子越小越靠前
4. 分母越小越靠前

## 注意事项

这个脚本只能根据显示出来的平均值推测可能组合，不能保证唯一正确答案。实际使用时建议结合游戏局势、已知数量范围和历史经验一起判断。
